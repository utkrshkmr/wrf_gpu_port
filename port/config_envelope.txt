# Supported-option envelope of the GPU port (plan.md 2.2, 2.3, P1.8).
#
# The envelope is the reference case's namelist (cases/eaton_20250108/
# namelist.input) with these changes:
#   free:   options that other fires may change freely (plan.md 2.3)
#   pinned: options that change executed code without being physics choices
#           (plan.md P1.8); if the reference namelist does not set them, a
#           new case must leave them at these values
# Every other option set in the reference namelist must have the same value
# in a new case, for every domain.  port/check_case.py and the Fortran
# startup gate gpu_check_config (plan.md P1.8) both follow this file; T-GATE
# (port/tests/gate/) checks that they agree.
